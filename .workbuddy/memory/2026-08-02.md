## OSGi 打包(09:30)

用户问如何打包成 OSGi bundle:
- core/pom.xml 加 felix maven-bundle-plugin 5.1.9,bundle goal 接管;BSN=com.alibaba.fastjson2,导出两个包
- 排坑:1) bnd 把 JDKUtils 的 android.os Class.forName 误判为依赖 → 删反射检测(顺便符合"纯 java 服务端");2) sun.misc.Unsafe 需 `sun.misc;resolution:=optional`(否则 bundle ACTIVE 但调用 NoClassDefFoundError);3) Private-Package 不能 !*(会打空 jar)
- 用真实 Felix 7.0.5 做冒烟:安装→启动→解析/序列化/指数拒绝/util 加载全通过
- **暴露并修复 bug**:write(Map/List) 值分支缺 BigInteger → 超出 long 的整数序列化抛异常;UTF8/UTF16 各补 2 处 writeBigInt 分支 + 回归测试 serializeBigInteger
- 146 测试全绿;jar 320KB(OSGi manifest 版)
- 经验:OSGi 场景 JDK 内部包(sun.misc)必须 Import-Package 标记 resolution:=optional,否则类加载隔离下找不到;验证 OSGi bundle 用 Felix 框架做冒烟比只看 manifest 可靠
